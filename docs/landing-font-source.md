# Landing Korean font

Noto Sans KR, SIL Open Font License 1.1. Official Google Fonts Korean subset, weight 400–900, self-hosted as WOFF2. The subset contains the Korean characters used in the landing page and shared footer at build time. Manrope continues to cover Latin text.

- Family: https://fonts.google.com/noto/specimen/Noto+Sans+KR
- License: https://github.com/google/fonts/blob/main/ofl/notosanskr/OFL.txt
- Source: Google Fonts CSS API, served from fonts.gstatic.com.
- Downloaded: 2026-10-31.
