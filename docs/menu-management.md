# 메뉴 관리 사진과 사장님 소개 개선

- 예시 메뉴의 기존 사진 URL을 관리 화면 왼쪽 미리보기로 표시한다. 사진 선택·제거는 기존 메뉴 저장 API를 사용한다. 새 이미지 업로드/생성 기능을 추가하지 않는다.
- 예시 불러오기·필드 편집·삭제·추가 시 변경 상태를 표시한다. 공개 성공 또는 최신 데이터 다시 불러오기 시 초안 안내를 지운다. 처리 중 편집은 비활성화한다.
- 사진 미등록·불러오기 실패·빈 메뉴 상태를 제공한다. 모바일에서는 사진이 상단 행 왼쪽에 남는다.
- 기존 AI 메뉴 읽기 프롬프트가 원문에 보이는 사실만으로 한·영 이름과 소개를 자연스럽게 다듬도록 조정됐다. 가격·재료·맛·분량 등의 근거를 만들지 않고, 읽지 못한 설명은 빈칸으로 둔다. 사장님이 확인한 뒤 공개한다.
- 랜딩의 소개 전후 문구는 설명용 예시다. 실제 AI 응답을 기록한 사례가 아니다.

검증: 타입 검사, 예시 3개 사진/사진 없음/빈 메뉴의 컴포넌트 HTML, 로컬 사진 응답, 선택·제거의 저장 및 손님 메뉴 반영을 확인했다. AI 설정은 로컬에서 비활성 상태이므로 실제 생성 품질 검증은 실행하지 않았다. 브라우저 호스트 사용 불가로 화면 배치·클릭 검수는 미실행이다.
